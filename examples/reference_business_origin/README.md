# Reference Business Origin (synthetic)

This example represents a **synthetic Business web origin** used only by the ABIS Reference Runtime demonstrator.

It exposes an implementation-level **Reference Runtime Pointer** at:

`/.well-known/abis-reference-runtime`

This is **not** a normative ABIS discovery mechanism and **not** `/.well-known/abis`.

Use `scripts/serve_reference_business_origin.py` to serve a live pointer that references a running Reference Runtime gateway.
